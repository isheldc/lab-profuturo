# LabInABox 🔬
Repositorio para el Hackathon ProFuturo - Reto 17: Un laboratorio de ciencias donde no existe un laboratorio[cite: 1].

## Descripción del Proyecto
Aplicación web interactiva de bajo coste diseñada para guiar a los estudiantes en el método científico (hipótesis, experimentación y conclusiones) sin necesidad de una conexión permanente a internet.
